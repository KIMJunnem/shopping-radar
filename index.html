구매 전에 이 네 가지만 확인

1. 단위가격

묶음 수량이 많다고 항상 싼 건 아닙니다. 100g·100ml·1개당 가격으로 비교하세요.

2. 배송 조건

로켓배송, 무료배송 여부와 도착 예정일은 결제 직전 다시 확인하세요.

3. 옵션 차이

같은 상품명이어도 용량·색상·세대·구성품이 다를 수 있습니다.

4. 최신 후기

오래된 후기보다 최근 후기에서 포장·품질·구성 변경 여부를 확인하는 편이 좋습니다.

가격 비교 방법

  1. 비교할 상품의 옵션을 동일하게 맞춥니다.
  2. 가격을 총 g·ml·개·매로 나눕니다.
  3. 배송비와 쿠폰 조건까지 포함한 결제 금액을 확인합니다.

묶음상품 비교 팁

낱개 용량 × 묶음 수량으로 총량을 구하세요. 500ml 6병은 3,000ml이며, 많이 살수록 보관 공간과 소비기한도 함께 확인해야 합니다.

ABOUT THE DATA

데이터 표시 기준

왜 지금 상품이 비어 있나요?

쿠팡 파트너스 API 최종 승인 전이기 때문입니다. 승인 전에는 판매량이나 인기순위를 임의로 추정하지 않습니다.

API가 열리면 무엇이 달라지나요?

카테고리별 베스트 상품, 가격, 상품 이미지, 순위 변동을 자동 저장하고 상품별 상세 페이지와 카테고리 페이지를 매일 갱신합니다.

가격은 실시간인가요?

API를 마지막으로 조회한 시점 기준입니다. 쿠팡에서 가격이 바뀌면 실제 결제 가격과 차이가 날 수 있습니다.

kg과 g, L와 ml도 비교할 수 있나요?

네. 계산기가 kg을 g으로, L를 ml로 환산해 같은 종류의 단위가격을 비교합니다.
